# Changelog

## 1.0.0-rc.11

Quality release: no new editor features, more confidence.

- **Automated tests (`npm test`).** About 60 checks that run with plain Node (no dependencies): save-time edits, shortcuts, settings.json validation, Markdown, token encryption, window state, and consistency checks (same version everywhere, offline file list complete, every icon has a glyph, extension catalog up to date, notices complete).
- **XSS review.** 94 places that build HTML were audited. Fixed: the Git branch name and repository name in the status bar, context menu labels (including extension menus), extension icon names and external links (only http/https). There is now a single escape helper (`js/escape.js`), exposed to extensions as `zern.util.escapeHtml`, and a test that fails when a new unescaped value reaches an HTML string.
- **Desktop window remembers** its size, position and whether it was maximized; if the monitor is gone it opens centered.
- The CDN fallback for Monaco now points to 0.57.0, the version bundled with Zern (it was 0.45.0).
- TODO Tree 1.0.1 and HTML Preview 1.2.1.
- Third-party notices corrected (Lora added, Bricolage Grotesque removed, TypeScript and Monaco's own notices referenced).

## 1.0.0-rc.10

- **GitHub token protected.** The desktop app keeps it in the system keyring (nothing in localStorage). On the web it lives only in the session; ticking "Remember on this device" stores it encrypted with a passphrase you type once per session, with an Unlock card in Source Control. A token saved in plain text by an older version is moved automatically.
- **Trust before running a project's scripts.** HTML Preview's full mode (same origin as Zern) now asks once per project; without trust it uses the isolated sandbox, and you can trust it later by clicking the Isolated tag. GitHub repositories are never trusted.
- The page no longer needs inline scripts (`js/boot.js`), and a minimal Content-Security-Policy blocks plugins and `<base>` hijacking. A stricter policy would break the isolated preview, so it is not included.
- **Ctrl+Q works with no file open:** it lists Zern's commands instead of doing nothing.
- **Extension API:** edit the active document (`zern.editor`), run code before saving, right-click menus in the editor and the Explorer, sidebar views with their own icon, quick pick and input box, project file listing and open-at-line.
- **Five new extensions:** Text Tools, TODO Tree, JSON Tools, Save Actions and Markdown Tools. HTML Preview 1.2.0 adds the trust step.
- The service worker now caches every file of every extension for offline use (`npm run catalog` writes the list).
- Removed `install.sh` (it installed a different, older project). The license and package author now read "Zern Code contributors".

## 1.0.0-rc.9

- **Modern icons.** The icon font Zern was using (Codicons 1.11, 462 icons) was older than the one inside Monaco (1.15, 647 icons), which is why the icons looked old whenever Zern's own font won over Monaco's. Zern's icons are now generated from the Codicons font and the icon table that ship inside the Monaco copy (`npm run icons`), so they are exactly the ones Monaco draws: all 785 icons use the same code as Monaco, and the 43 the app uses are pixel-identical.
- Removed the separate Codicons copy (`assets/vendor/codicons`) and the `@vscode/codicons` dev dependency: there is a single source of icons now.

## 1.0.0-rc.8

- **Icons, for real this time.** Zern's icons now use their own class prefix (`zi-`) and their own font, embedded in `css/icons.css` (generated from the Codicons copy with `npm run icons`). Monaco ships its own `.codicon` classes and `codicon` font, and the two were overriding each other depending on the browser and on which stylesheet loaded last. They no longer share anything, so Monaco cannot change Zern's icons.
- The service worker now bypasses the browser's HTTP cache when installing and revalidating files, so a new release can't be filled with stale copies of the old one. If the page and the scripts ever come from different releases, Zern says so.

## 1.0.0-rc.7

- **settings.json is now a tab**, like in VS Code, not a modal. Ctrl+S validates and applies it (nothing is applied if something is wrong), it never autosaves half-typed, and it refreshes by itself when you change settings elsewhere and have no unsaved edits.
- **Web icons.** The app's icons are now locked to their own font (`css/codicons.css`), so they can no longer switch to the older icons bundled inside Monaco depending on which stylesheet loads last.
- **Web offline.** The check for the local Monaco used a request the service worker never answers, so offline it fell back to the CDN and failed even with everything cached. It now works offline. Monaco is cached in the background (its own cache, not re-downloaded on every release) and the file list is generated by `npm run vendor`.
- Help > About now shows whether the editor engine is the local copy or the CDN.
- The "new version is ready" message no longer appears on the very first visit.

## 1.0.0-rc.6

- **Fully offline.** Monaco, the icons (Codicons) and JSZip are now bundled in `assets/vendor/`; nothing is downloaded at startup. `npm run vendor` refreshes them from `node_modules`.
- **Customizable shortcuts.** New **Keyboard Shortcuts** screen (File menu, Settings, Command Palette): search every command, record a new combination, reset or remove it, with conflict and reserved-key warnings. Menus show the current shortcut. Extension commands can be rebound too.
- **settings.json.** Every setting plus your shortcuts as one JSON document, with autocomplete, hover docs and validation. Nothing is applied until it is valid.
- **Desktop app (Linux ARM64 .deb).** Zern icon in the launcher and window. Frameless window using Zern's own title bar, with minimize, maximize/restore and close buttons like VS Code (double click on the bar maximizes). The native menu is gone, which also frees Ctrl+W and Ctrl+R for the editor. Links open in your browser.
- Fixed: the `extensions/` folder was missing from the desktop build. In the desktop app the extension catalog now comes from a bundled module (`npm run catalog`), because `fetch()` on local files is unreliable there.
- Global shortcuts (Ctrl+P, Ctrl+S, Ctrl+B, Ctrl+Q, ...) now run from one registry instead of several scattered handlers.

## 1.0.0-rc.5

- **Emmet removed for now.** It will come back in a later version. The extension, its Tab key hook and its registry entry are gone; anyone who had installed it in rc.4 is cleaned up automatically and nothing else changes.

## 1.0.0-rc.4

- **Markdown Preview** (new extension): live preview with scroll sync, task lists, tables and nested lists. `Ctrl+Alt+M`.
- **Emmet** (new extension): expand HTML and CSS abbreviations with Tab (`ul>li*3`, `m10`, `df`). Works offline, no server needed.
- **HTML Preview 1.1.0**: new settings (auto reload, reload delay, default screen size).
- **Settings per extension:** extensions declare them in their manifest and they appear in a Settings tab of the details page.
- **Suggestions:** opening an `.html` or `.md` file suggests the matching extension, with "Don't show again".
- **Update indicator:** when an extension changes version, the list shows an Updated mark, the details page a banner and a link to the changelog, and a toast announces it.
- Extension API: `zern.settings`, `zern.editor` (Tab expanders, scroll events) and `zern.markdown`.
- Markdown renderer: nested lists, task lists and strikethrough.

## 1.0.0-rc.3

- **Extensions.** New Extensions view (activity bar, `Ctrl+Shift+X`) with Installed and Available lists, a VS Code-style details page (Details, Features, Changelog), and install, uninstall, enable and disable. Only extensions published by the Zern team can be installed, marked with a verified badge. They live in the new `extensions/` folder.
- **HTML Preview** (first extension). Real, live preview next to the editor: relative CSS, JS, images and links work, console output is captured, responsive sizes, address bar. `Ctrl+Alt+V` or the status bar button.
- Extension API (`zern.commands`, `workspace`, `window`, `serve`, `storage`) documented in `extensions/README.md`.
- The service worker can now serve virtual files to extensions under `/__zern_ext__/`.

## 1.0.0-rc.2

- Project renamed from KCode to **Zern Code** (short name: **Zern**), with new logos and icons.
- The Zern logo (title bar, empty-editor watermark, About dialog and tab favicon) now follows the active theme's accent color.
- New welcome page. Existing local data (session, GitHub token, settings) is migrated automatically from the old `kcode_*` keys.

## 1.0.0-rc.1

- Monaco editor with 8 themes, tabs, breadcrumbs, Go to Definition, HTML tag auto-close and a Problems panel.
- Real folders (File System Access API) or a virtual project; restores open tabs, cursor and scroll.
- GitHub: connect with a token, open any repository, see changes, diff, stage, commit & push, pull, branches, new-commits alert.
- VS Code-style interface: menu bar, command center, status bar, Quick Open and Command Palette.
- Installable PWA with a first-run welcome page.
