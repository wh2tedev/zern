# Changelog

## 1.2.1

- The 404 page also escapes quotes in the missing path.

## 1.2.0

- Asks you to trust a project before running its scripts in the full preview. Untrusted projects use the isolated sandbox.

## 1.1.0

- New settings: auto reload, reload delay and default screen size.
- Zern now suggests this extension when you open an `.html` file.

## 1.0.0

- First release.
- Real preview served through the Zern service worker, with live reload, console, address bar and responsive sizes.
- Isolated sandbox mode for GitHub repositories.
