# Markdown Preview

Read your Markdown as you write it.

## Features

- **Live.** The preview refreshes as you type, including unsaved changes.
- **Scroll sync.** Scroll the editor and the preview follows.
- **Safe.** Raw HTML in the file is shown as text, never executed.
- **Images.** Relative images from your project show up (real folders); `https` images work everywhere.
- **Task lists, tables, nested lists, code blocks** and block quotes.

## Usage

1. Open a `.md` file.
2. Press `Ctrl+Alt+M`, click **Preview** in the status bar, or run **Markdown Preview: Open Preview to the Side** from the Command Palette (`Ctrl+Q`).

## Settings

| Setting | What it does |
|---|---|
| Sync scroll | Keeps the preview aligned with the editor |
| Font size | Text size of the preview (12 to 24) |
| Refresh delay | Wait after typing before refreshing |

## Good to know

- Relative images only work in real folders; the virtual filesystem and GitHub repositories store text only.
- Nested lists, tables and task lists are supported; footnotes and embedded HTML are not.
