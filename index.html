      Features

      Everything a desktop editor does. Nothing it makes you wait for.

      Dark 2026, Nordic, Monokai, Light Modern and more. They restyle the whole editor, not just the code colors.

      Extensions

      Install, disable or remove them from the Extensions view (Ctrl+Shift+X). Only extensions published by Zern are available, marked with a verified badge.

      FAQ

      Short answers.

      Is Zern free?

      Yes. Zern is open source under the MIT license. There is no account and nothing to pay.

      Where are my files, and what do you collect?

      Your files stay in your browser or on your disk. Zern has no analytics and no server of its own. The only things it contacts are GitHub (when you use the GitHub features) and Google Fonts (for the typefaces). Read the Privacy page for the details.

      Does it work offline?

      Yes. The web version caches itself after the first visit, and the desktop app ships with everything it needs. Without a connection the typefaces fall back to your system fonts.

      Which browsers are supported?

      Chrome and Edge support everything, including real folders. Firefox and Safari support virtual projects and GitHub.

      Is it the same as VS Code?

      No. Zern is an independent project built on the Monaco editor, the engine behind VS Code. It is not affiliated with or endorsed by Microsoft or GitHub.
